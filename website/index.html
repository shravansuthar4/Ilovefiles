Three moves. That’s it.

  1. 1

    Drag a file

    Any photo, song, video, Word document or PDF, from Finder, Explorer or the desktop.

  2. 2

    Press C

    While still holding it. A glass ring of every format it can become appears around it.

  3. 3

    Drop on a format

    It lights up blue; let go. The new copy lands next to the original, which stays untouched.

How to install

Mac

  1. Click Download for Mac: Apple silicon for M-series Macs, Intel for older ones (not sure? Apple menu → About This Mac). Open the downloaded .dmg file.
  2. Drag the I love files icon onto the Applications folder.
  3. Open Applications and double-click I love files. If your Mac says it can’t verify the app, click Done.
  4. Go to System Settings → Privacy & Security, scroll down and click Open Anyway, then Open. Only needed the first time.
  5. When asked, switch on Accessibility for I love files, so it can notice the C key.
  6. A ♡ appears in the menu bar. Done: it starts by itself from now on.

Windows

  1. Click Download for Windows and open I-love-files-Windows-Setup.exe.
  2. If you see “Windows protected your PC”, click More info, then Run anyway.
  3. It installs by itself in a few seconds. There’s nothing to click through.
  4. A pink ♡ appears in the system tray, by the clock (it may be under the ^ arrow). It starts with Windows from now on.

Uninstall: on Mac, quit from the ♡ menu and drag the app to the Bin. On Windows, use Settings → Apps → I love files → Uninstall.
